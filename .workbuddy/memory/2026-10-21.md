# 2026-10-21

## 打包单文件 exe
- 新增 `build_exe.py`：PyInstaller `--onefile --windowed`，产物 `dist/TextLens.exe`（约 55MB，自包含）。
  - 资源用 `--add-data assets/float.png;assets`、`app.ico` 打进去。
  - winrt（Windows OCR）是原生 .pyd，必须 `--collect-all=winrt`，否则 OCR 引擎起不来。
  - 排除了 numpy/tkinter/matplotlib/scipy/pandas/torch/IPython/pytest 控制体积。
  - 默认增量打包（30~60s），`python build_exe.py --clean` 才全量（约 1.5 分钟）。
- `main.py` 的 `BASE_DIR` 改为打包感知：frozen 时取 `sys._MEIPASS`，否则取脚本目录。
- 冒烟测试：`timeout 12s ./dist/TextLens.exe` 退出码 124 = 未崩溃。

## 打包后自动清理 .spec
- `build_exe.py` 增加 `_cleanup_spec()`：打包成功后删除自动生成的 `TextLens.spec`，保持目录干净。
- 坑：`PyInstaller.__main__.run()` 成功时返回 **None 而不是 0**，`if rc == 0` 会静默失效，必须写 `if rc in (0, None)`。
- 已验证：增量打包输出末尾出现"已清理 ...TextLens.spec"，项目根目录不再残留该文件，exe 冒烟测试正常。
